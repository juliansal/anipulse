# AniPulse (Rails)

## Project Description

**AniPulse** is a web application designed for anime enthusiasts to discover, track, and discuss anime shows and movies. Users can maintain personalized watch lists categorized by viewing status (Watching, Completed, Paused, Pass, Planning) and engage with the community through dedicated discussion rooms for each anime title.

## Key Goals & Scope

1. **Catalog Management:** Ingest and normalize anime data (bulk upload MVP, expanding to API integration like Jikan).
2. **User Authentication & Dashboard:** Personal accounts to manage profile settings and view viewing stats.
3. **Watch Lists:** Comprehensive tracking board broken down by custom viewing statuses.
4. **Community Discussion Rooms:** Dedicated thread-based social spaces for every catalog entry.
